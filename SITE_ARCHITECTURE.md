# Site Architecture

## Routes

```text
/
/work
/work/evalforge
/work/agentscope
/work/estate-ai
/work/launchkit-ai
/about
```

Optional later:
- `/resume`
- `/uses`
- `/notes`

Do not add a blog/notes section until there is real content.

## Header
Desktop:
`JAMES.                    WORK   ABOUT   CONTACT`

Mobile:
`JAMES.                                  MENU`

Header may become sticky after slight scroll. Keep mobile navigation simple and accessible.

## Homepage
### Hero
- compact metadata label: AI-FOCUSED SOFTWARE ENGINEER
- brand/name treatment
- primary positioning line
- short supporting paragraph
- CTA: Selected Work
- secondary contact/collaboration signal only if accurate

### Selected Work
Four editorial project blocks, not a uniform generic card grid.
Order:
1. EvalForge
2. AgentScope
3. EstateAI
4. LaunchKit AI

Each block includes:
- order
- title
- category
- summary
- role
- stack
- year/status
- project visual
- case-study link

### AI Evaluation Focus
Headline concept:
`AI systems need more than demos. They need evidence.`

Capability areas:
- Benchmark Design
- Agent Evaluation
- Rubric Design
- Failure Analysis

### Engineering Expertise
Organize by capability, not proficiency percentages:
- AI Systems
- Product Engineering
- Web
- Infrastructure
- Additional Experience

### Selected Professional Work
Private categories:
- Private SaaS Products
- Real-Estate Software
- AI Evaluation
- Mobile & Blockchain

### About Preview
Short professional narrative and link to `/about`.

### Contact
Primary channels:
- Email
- GitHub
- LinkedIn

Do not invent URLs. Use configuration/placeholders until supplied.

## Work Index
Editorial archive showing flagship and secondary projects.
Flagship projects can have larger visuals; ChainLens and PocketAI can be smaller rows.
