# Portfolio Project Portfolio

## Flagship Projects

### 1. EvalForge
Category: AI Evaluation Infrastructure
Purpose: prove AI evaluation, benchmark, asynchronous execution, scoring, failure-analysis, and full-stack architecture capability.
Preferred stack: Next.js, TypeScript, FastAPI, Python, PostgreSQL, Redis, background worker, Docker.
Primary deep dive: asynchronous evaluation execution and aggregation.

### 2. AgentScope
Category: AI Agent Observability
Purpose: prove agent execution observability, trace modeling, SDK design, diagnostics, and AI infrastructure capability.
Preferred stack: Next.js, TypeScript, FastAPI/Python, PostgreSQL, Redis, lightweight Python SDK.
Primary deep dive: trace ingestion and hierarchical span reconstruction.

### 3. EstateAI
Category: AI Product / Real-Estate Intelligence
Purpose: prove product engineering, deterministic business logic, maps/data visualization, full-stack architecture, and responsible AI integration.
Preferred stack: Next.js, TypeScript, FastAPI/Python, PostgreSQL/PostGIS, MapLibre, charts, Docker.
Primary deep dive: separating deterministic financial calculations from generative AI.

### 4. LaunchKit AI
Category: Production SaaS Infrastructure
Purpose: prove multi-tenant architecture, authorization, usage metering, billing concepts, background jobs, auditability, and TypeScript-heavy product engineering.
Preferred stack: Next.js, TypeScript, PostgreSQL, Redis, background worker, Stripe test mode, Docker.
Primary deep dive: tenant-aware authorization.

## Project Evidence Requirements
For a flagship project to be marked complete in the portfolio, it should have:
- functioning demo or locally reproducible workflow
- public repository
- README with quick start
- architecture documentation
- tests
- CI
- seeded realistic demo data
- polished screenshots
- case study
- honest project status

## Public Status Values
- In Development
- Open Source
- Live

Do not show `Live` or `Open Source` until the relevant links and implementations exist.
