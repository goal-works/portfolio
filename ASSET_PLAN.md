# Asset Plan

## Flagship Project Assets
For each completed flagship project, prepare:
- `cover.webp`
- `dashboard.webp`
- `detail.webp`
- `mobile.webp`
- `architecture.svg`
- `og.png`

Additional screenshots should reflect actual important states, not decorative mockups.

## Recommended Sizes
- desktop project screenshots: approximately 1600×1000
- social preview: 1200×630
