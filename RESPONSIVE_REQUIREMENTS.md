# Responsive Requirements

## Required Verification Widths
At minimum verify:
- 375px
- 430px
- 768px
- 1024px
- 1440px
- 1920px

## Mobile Principles
Mobile must be deliberately designed, not merely scaled down.

Required:
- impactful but non-overflowing hero
- single-column content flow where appropriate
- metadata stacks cleanly
- no clipped project titles
- project images maintain useful aspect ratios
- tables become scrollable or transform into mobile-friendly layouts
- architecture diagrams may use controlled horizontal scrolling if necessary
- mobile menu is keyboard/screen-reader accessible
- touch targets are comfortably sized

## Tablet
Use tablet-specific spacing and layout decisions rather than treating tablet as desktop.

## Desktop
Maintain generous spacing and editorial hierarchy without creating large accidental dead zones.

## Image Behavior
- project screenshots should have consistent aspect-ratio treatment
- avoid stretching/cropping critical interface elements
- use responsive image loading
- meaningful alt text required

## Overflow
No unintended horizontal page scrolling at any target width.
